## Prompts Rules

### Structure

- Repository name - `prompts`
- `README` required
  - One-sentence description in English and Polish
- Root is source for GitHub Pages
- Main `index` required in English
- GitHub Pages title: Prompts
- Use [kebab-case](../../convention/naming.md) for all folders and files
- Content organized under:

  - `en/`
  - `pl/`
- Category folders define content areas
- Any folder may contain its own `index`

### Content

- Polish versions are optional
- Prompts
- Rules
- Document templates

- [Single commit history](../../convention/single-commit.md)
  - commit message - prompts
